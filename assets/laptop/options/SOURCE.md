# Laptop mockup source

The front-facing laptop is adapted from [Mockups Design's "Free MacBook Air 2022 mockup" pack](https://mockups-design.com/free-macbook-air-2022-mockup/).

The retained export uses the Natural portrait treatment. The portrait was colour-graded from the original local cut-out; it was not regenerated. A subtle matte webcam cover replaces the visible lens and activity light in the source mockup.

The source page identifies the pack as free for private and commercial use with no attribution required. The exported portfolio assets have transparent backgrounds, custom screen artwork, and AVIF/WebP delivery formats. The original PSD file is not redistributed in this repository.
