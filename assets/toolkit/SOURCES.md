# Toolkit icon sources

The toolkit carousel stores its SVG icons locally so the portfolio does not depend on a third-party image API at runtime.

- Coloured technology logos: [gilbarbara/logos](https://github.com/gilbarbara/logos)
- Monochrome product logos: [Simple Icons](https://github.com/simple-icons/simple-icons)
- Figma, WordPress, Git, VS Code and LocalWP reuse the portfolio’s existing dock assets.

Brand names and logos remain the property of their respective owners.
